# Sito web - Programma svolto di Sistemi Operativi

Questo progetto è un sito web statico realizzato in **HTML e CSS** per presentare il programma svolto di Sistemi Operativi e raccogliere i lavori realizzati durante l'anno scolastico.

## Contenuto del sito

Il sito è diviso in tre sezioni principali:

1. **Sistemi Operativi**: ricerca teorica, domande con risposte e presentazione PowerPoint sui sistemi operativi.
2. **Unix**: breve riassunto sulla storia, sulle caratteristiche principali e sulla sua importanza nei sistemi moderni.
3. **Virtualizzazione**: relazione pratica sulla creazione di una macchina virtuale con Ubuntu tramite Oracle VirtualBox.

## Tecnologie utilizzate

- HTML5 per la struttura del sito.
- CSS3 per lo stile grafico e il layout responsive.
- Google Fonts per i caratteri tipografici.

## File del progetto

- `sistemi-operativi-sito.html`: pagina principale del sito.
- `assets/`: cartella che contiene immagini e documenti allegati.
- `Relazione_Virtualizzazione.docx`: relazione sul lavoro di virtualizzazione.
- `Sistemi_Operativi.docx`: documento con domande e risposte.
- `Sistemi_Operativi.pptx`: presentazione sui sistemi operativi.

## Obiettivo del progetto

L'obiettivo del sito è presentare in modo chiaro, semplice e ordinato il programma svolto di Sistemi Operativi, mostrando sia la parte teorica sia la parte pratica del lavoro svolto.

## Galleria immagini

La sezione finale del sito contiene una galleria con le schermate principali del progetto di virtualizzazione, come il download dei software, la configurazione della macchina virtuale, l'installazione di Ubuntu, la cartella condivisa e la gestione degli utenti.]]]]]

## Avvio del sito

Per visualizzare il progetto basta aprire il file HTML principale in un browser, ad esempio Google Chrome, Microsoft Edge o Mozilla Firefox.

## Note finali

Il sito è stato pensato come progetto scolastico, con una struttura essenziale, leggibile e facile da consultare.
